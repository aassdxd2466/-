## Blockcraft

브라우저에서 바로 실행되는 마인크래프트 스타일 복셀 샌드박스입니다. 빌드 과정 없이 `index.html` 하나로 동작합니다 (Three.js r128을 CDN에서 불러옴).

### 실행

`index.html`을 브라우저로 열거나, 간단한 정적 서버로 띄우세요.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

### 기능

- 무한 절차적 지형: 평원, 숲, 사막(선인장), 바다와 해변, 눈 덮인 산
- 동굴, 석탄·철·금·다이아몬드 광석, 기반암
- 나무, 풀, 장미, 민들레
- 블록 부수기/놓기 (25종), 블록 가방(E), 핫바 1–9
- 걷기, 달리기, 점프, 수영, 비행 (스페이스 두 번 또는 F)
- 앰비언트 오클루전과 하늘빛 그림자 (동굴은 어둡게)
- 낮/밤 순환, 해·달·별, 흐르는 구름
- 돌아다니는 돼지 (때리면 도망감)
- TNT: 부수면 불이 붙고 2초 뒤 폭발, 연쇄 폭발
- 블록 파편 파티클, 효과음 (Web Audio)
- 월드 자동 저장 (localStorage)
- 모바일 터치 조작 (가상 조이스틱, 버튼)

### 조작

| 키 | 동작 |
| --- | --- |
| WASD | 이동 (Shift 달리기) |
| Space | 점프, 두 번 누르면 비행 |
| 비행 중 Space / Shift | 상승 / 하강 (Ctrl 빠르게) |
| 좌클릭 | 블록 부수기, 돼지 때리기 |
| 우클릭 | 블록 놓기 |
| 휠 클릭 | 보고 있는 블록 집기 |
| 1–9, 휠 | 핫바 선택 |
| E | 블록 가방 |
| T | 시간 넘기기 |
| F3 또는 ` | 디버그 정보 |
| Esc | 메뉴 |

모든 텍스처는 코드로 그려서 생성하므로 외부 이미지 파일이 없습니다.
