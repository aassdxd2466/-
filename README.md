# Blockcraft

브라우저에서 바로 실행되는 마인크래프트 스타일 복셀 게임입니다. 빌드 과정 없이 `index.html`과 `js/` 폴더만으로 동작합니다. Three.js 0.186.1을 ES 모듈(import map)로 jsDelivr에서 불러오고, `three/addons`의 Sky 셰이더를 씁니다. 모든 텍스처와 아이콘은 코드로 그려서 만들기 때문에 이미지 파일이 없습니다.

## 실행

```bash
python3 -m http.server 8000
# http://localhost:8000
```

ES 모듈을 쓰기 때문에 `index.html`을 파일로 직접 열면 브라우저가 막습니다. 위처럼 로컬 서버로 여세요.

## 게임 모드

- **서바이벌**: 체력, 배고픔, 산소, 낙하 피해, 화상, 익사, 굶주림. 블록은 도구로 시간을 들여 캐야 하고, 캔 블록은 아이템으로 떨어집니다. 죽으면 아이템을 그 자리에 떨어뜨리고 처음 위치에서 다시 태어납니다.
- **크리에이티브**: 즉시 부수기, 비행, 블록 팔레트에서 모든 아이템을 꺼내 쓰기.
- **난이도**: 평화로움(좀비 없음, 배고픔 없음) · 보통 · 어려움(좀비가 더 세고 굶어 죽을 수 있음).

## 들어 있는 것

- **월드**: 평원, 자작나무 숲, 설원(가문비나무, 얼음), 사막(사암, 선인장, 마른 덤불), 산(눈 덮인 봉우리), 바다와 해변(점토, 사탕수수). 동굴, 깊은 곳의 용암 호수, 동굴 천장의 발광석, 버섯.
- **블록 65종**: 원목·판자 3종, 석재 벽돌, 이끼 낀 조약돌, 사암, 흑요석, 얼음, 눈 블록, 점토, 호박, 잭오랜턴, 수박, 양털 6색, 철·금·다이아몬드 블록, 광석 7종(석탄·철·금·다이아몬드·청금석·레드스톤·에메랄드), 작업대, 화로, 상자, 양조기, 사다리, 횃불, 발광석, TNT 등.
- **빛**: 횃불·발광석·잭오랜턴·용암이 15단계 블록 빛을 퍼뜨립니다. 하늘빛과 따로 계산해서 밤과 동굴은 어둡고, 불빛은 따뜻한 색으로 비춥니다.
- **흐르는 물과 용암**: 물은 아래로 떨어지고 옆으로 7칸까지 퍼집니다. 무한 수원도 만들 수 있어요. 용암은 느리게 흐르고, 물과 만나면 흑요석이나 조약돌이 됩니다. 물이 횃불과 꽃을 쓸어갑니다.
- **도구**: 나무·돌·철·다이아몬드 곡괭이·도끼·삽·검. 블록마다 알맞은 도구와 단계가 있고 내구도가 닳습니다.
- **제작**: 레시피 목록에서 바로 만들기. 작업대·화로·양조기 근처에서만 되는 레시피가 있고, 화로는 연료(석탄, 판자, 원목)를 씁니다.
- **음식**: 사과, 돼지고기, 양고기(날것/익힌 것), 수박, 버섯 스튜, 황금 사과, 썩은 살점(허기 효과).
- **물약 11종**: 신속, 즉시 치유, 재생, 야간 투시, 힘, 수중 호흡, 도약, 화염 저항, 투명화, 저항, 느린 낙하. 유리병으로 물을 떠서 양조기 근처에서 재료와 함께 만듭니다. 효과는 화면 오른쪽 위에 남은 시간과 함께 표시됩니다.
- **몹**: 돼지, 양(양털), 좀비(어둠 속에서 생기고 햇빛에 탐).
- **실사 조명 (그래픽 1단계)**: ACES 톤매핑과 sRGB 출력, 물리 기반 재질(PBR). 대기 산란 하늘(Sky 셰이더), 태양 DirectionalLight(4096 그림자맵, 플레이어를 따라가며 텍셀 단위로 스냅), 하늘빛 HemisphereLight, 5초마다 하늘을 구워 만드는 환경맵(간접광·반사). 하루 20분, 새 월드는 늦은 오후 골든아워에 시작합니다. 밤에는 푸른 달빛과 반짝이는 별 3,500개. 구름 그림자와 동굴의 어둠, 횃불 빛은 새 조명에 맞게 그대로 유지됩니다. 메뉴에서 노출(0.5–1.5)과 그림자를 조절할 수 있어요. 조절 가능한 수치는 `js/render.js` 맨 위 `LIGHTING`에 모여 있습니다.
- **PBR 블록 재질 (그래픽 2단계)**: 블록마다 128×128 텍스처 세트(색, 노멀, 틈새 그늘·거칠기·금속 마스크)를 게임을 열 때 코드로 생성합니다. 여러 옥타브의 이음매 없는 노이즈와 셀(보로노이) 노이즈로 질감을 만들고, 노멀맵은 높이 텍스처에 Sobel 필터를 걸어 만듭니다. 모든 블록이 MeshStandardMaterial이고 거칠기는 돌 0.9 · 흙 1.0 · 풀 0.85 · 나무 0.8 · 모래 0.95 · 잎 0.7 · 유리 0.05, 광석은 광물이 박힌 부분만 금속성 0.6입니다. 텍스처 아틀라스 없이 블록 종류마다 개별 텍스처를 쓰고 청크 메시를 재질 그룹으로 나눠 그려서 밉맵 번짐이 없습니다(트라이리니어 필터 + 하드웨어 최대 비등방성). 블록마다 텍스처 방향과 색조가 조금씩 달라 반복 무늬가 덜 보이고, 풀 윗면 색은 지역마다 다릅니다. 조절 값은 `js/blocktex.js`(타일별 `rough`·`metal`·`bump`)와 `js/mesher.js`의 `TINT`에 있습니다.
- **하늘과 그림자**: 바람에 천천히 흘러가는 입체 구름. 해의 방향에 따라 나무, 건물, 몹, 내 몸까지 실시간 그림자를 드리우고, 아침저녁에는 그림자가 길어집니다. 구름 그림자가 땅 위로 지나갑니다.
- **그 밖에**: 상자 보관, 묘목 키우기, 양동이, TNT 연쇄 폭발, 낮과 밤, 구름, 효과음, 자동 저장(localStorage), 휴대폰 터치 조작.

## 조작

| 키 | 동작 |
| --- | --- |
| WASD | 이동 (Shift 달리기, C 웅크리기) |
| Space | 점프 (크리에이티브에서 두 번 누르면 비행) |
| 좌클릭 | 꾹 눌러 캐기, 몹 공격 |
| 우클릭 | 놓기, 먹기/마시기, 상자·작업대·화로·양조기 열기, 양동이 쓰기 |
| E | 가방과 제작 |
| Q | 아이템 버리기 (Shift+Q 묶음째) |
| 1–9, 휠 | 핫바 선택 |
| 휠 클릭 | 보고 있는 블록 집기 |
| T | 누르고 있으면 시간 빨리감기 |
| F3 | 디버그 정보 |
| Esc | 메뉴 |

가방에서는 칸을 눌러 집고 다른 칸에 놓습니다. 오른쪽 클릭은 반만 집기, Shift+클릭은 빠르게 옮기기입니다.

## 시작 가이드 (서바이벌)

1. 나무를 캐서 원목을 얻고, 가방(E)에서 판자 → 작업대를 만듭니다.
2. 작업대를 놓고 근처에서 나무 곡괭이를 만들어 돌을 캡니다.
3. 석탄으로 횃불을 만들어 밤과 동굴을 밝히세요. 좀비는 어두운 곳에서 생깁니다.
4. 조약돌 8개로 화로를 만들고 철 광석을 구워 철 도구와 양동이를 만듭니다.
5. 유리병에 물을 담고 양조기에서 물약을 만들어 보세요.

## 파일 구조

| 파일 | 내용 |
| --- | --- |
| `js/core.js` | 상수, 노이즈, 블록·아이템·레시피·물약 정의 |
| `js/texlib.js` | 절차적 텍스처 도구: 이음매 없는 노이즈, 셀 노이즈, Sobel 노멀, ORM 굽기 |
| `js/textures.js` | 아이템 픽셀 아트, HUD 아이콘, 블록 깨짐 단계 |
| `js/blocktex.js` | 블록별 PBR 텍스처 디자인과 재질 수치, 인벤토리 아이콘 |
| `js/boot.js` | Three.js와 addons를 ES 모듈로 불러온 뒤 게임 스크립트를 순서대로 실행(중간에 블록 텍스처 생성) |
| `js/render.js` | 렌더러, 조명 수치(`LIGHTING`), 하늘·낮밤, 태양 그림자, 입체 구름, 파티클, 손에 든 아이템 |
| `js/world.js` | 지형 생성, 블록 빛 전파, 물·용암 흐름, 묘목, 충돌 |
| `js/mesher.js` | 청크 메시 생성(재질 그룹, 텍스처 방향·색조 변화), 청크 로딩 |
| `js/entities.js` | 효과음, 떨어진 아이템, 몹, TNT |
| `js/player.js` | 체력·배고픔, 효과, 인벤토리, 채굴, 아이템 사용 |
| `js/ui.js`, `js/invui.js` | HUD, 메뉴, 입력, 가방·상자·제작 화면 |
| `js/main.js` | 저장/불러오기, 메인 루프 |
