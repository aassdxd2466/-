# 잎새마을 휴가

던전에 지친 모험가가 숲속 마을에서 쉬어 가는 도트 그래픽 힐링 게임입니다. 던파(던전앤파이터) 마을 같은 2.5D 횡스크롤 화면과 HUD 감성을 참고했지만, 캐릭터·배경·아이콘·음악은 전부 코드로 새로 그리고 만들었습니다. 원작 리소스는 쓰지 않았습니다.

빌드 과정 없이 `index.html` 하나로 동작합니다. 외부에서 불러오는 건 Google Fonts(도현, 고운돋움)뿐입니다.

## 실행

`index.html`을 브라우저로 열거나 정적 서버로 띄우세요.

```bash
python3 -m http.server 8000
# http://localhost:8000/leaf-village/
```

## 할 수 있는 것

- **텃밭**: 씨앗을 심고 물을 주면 자라요. 젖은 흙이 마르면 다시 물을 줘야 하고, 비 오는 날엔 하늘이 대신 줍니다. 딸기·당근·튤립·해바라기·밤에 빛나는 별빛꽃.
- **낚시**: 연못가나 선착장 끝에서 찌를 던지고, 입질이 오면 움직이는 막대를 초록 칸에 맞춰 X. 시간대·날씨·레벨에 따라 잡히는 물고기가 달라요 (무지개송어는 아침, 달빛메기는 밤, 황금잉어는 Lv.3부터).
- **이웃**: 루미 할머니, 꼬마 토토, 상인 베른. 매일 말을 걸고, 좋아하는 선물을 주고, 게시판의 부탁을 들어주면 친해져요.
- **동물**: 고양이 나비와 병아리를 쓰다듬을 수 있어요. 나비와 충분히 친해지면 따라다닙니다.
- **밤**: 가로등과 창문, 천년나무의 등불이 켜지고 연못가에 반딧불이가 나와요. 모닥불에 앉아 쉬거나 생선을 구울 수 있어요.
- **힐링 레벨**: 모든 활동이 힐링 포인트(분홍 숫자)를 줘요. 레벨이 오르면 새 씨앗과 물고기가 열려요.
- **하루 결산**: 저녁 6시 이후 집에서 잠들면 그날의 휴식 등급(SSS~C)과 기록이 나와요.
- 우체통 편지, 우물 소원, 감정 표현, 도감, 낮과 밤·비·무지개, 절차적으로 만든 오르골 배경음악과 환경음.
- 진행 상황은 브라우저(localStorage)에 자동 저장됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| 방향키 / WASD | 이동 (같은 방향을 빠르게 두 번 누르면 달리기) |
| X (J, Enter) | 행동: 대화, 심기, 물 주기, 수확, 쓰다듬기, 낚시 |
| C (K, Space) | 점프 |
| Z | 앉기 (앉아 있으면 천천히 힐링) |
| 1 · 2 · 3 | 인사 · 만세 · 하트 |
| I · B · M · Esc | 가방 · 도감 · 소리 · 메뉴 |

휴대폰에서는 화면의 조이스틱과 X·C·Z 버튼으로 조작합니다. 조이스틱을 끝까지 밀면 달려요.
